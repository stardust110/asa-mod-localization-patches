# ASA Mod Localization Patch 0.1.31

## 3+1 package layout

This release changes the self-contained package back to a simple four-runtime-file layout:

- `ShooterGame-Windows_P.pak`
- `ShooterGame-Windows_P.ucas`
- `ShooterGame-Windows_P.utoc`
- `pakchunk9999-Windows_P.pak`

The first three files are the verified normal or bilingual baseline, preserved byte-for-byte. The fourth file now merges the full LocRes routing and the direct cooked-asset repairs. Extract every game file to `ShooterGame\Content\Paks`; install either the normal package or the bilingual package, never both.

## Fixed coverage

- Extra Bosses and Sweet Structures direct asset text
- Crystal Skins, Elven Structure Skins, and Arcadian Premium direct asset text
- Existing `Game` and `ShooterGame` language fallback routes

The normal Chinese package has passed live-game verification for Dream DodoReaper interaction/status text and Sweet Structures skin item names. This release does not replace or repack the `ShooterGame-Windows_P` baseline container, preventing the English fallback regression from 0.1.27.

`SHA256SUMS.txt` covers both ZIP downloads.
