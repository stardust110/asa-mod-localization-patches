# ASA Mod Localization Patch 0.1.27
# ASA 模组汉化补丁 0.1.27

## Both Packages Are Back / 两种安装包同时提供

This release includes both the normal-Chinese and bilingual packages. Download
and install exactly one package; they must not be mixed.

本版本同时提供普通中文包与双语包。请只下载并安装其中一个，不能混装。

- Normal Chinese: `ASA_Mod_Localization_0.1.27.zip`
- Bilingual: `ASA_Mod_Localization_Bilingual_0.1.27.zip`
- 普通中文：`ASA_Mod_Localization_0.1.27.zip`
- 双语：`ASA_Mod_Localization_Bilingual_0.1.27.zip`

## Direct Asset Repair / 直接资产文本修复

Earlier coverage for the following skin mods was limited to LocRes strings.
Their in-game item names and descriptions are stored directly in cooked asset
packages, so those strings could still remain English. This release adds a
separate `_P` IoStore asset overlay for the player-visible text in:

- Crystal Skins
- Elven Structure Skins
- Arcadian Premium

此前这三套皮肤模组只补了 LocRes；但游戏内物品名称和说明实际存放在已烹饪资产中，
因此仍可能显示英文。本版本为下列模组的玩家可见文本追加独立 `_P` IoStore 资产覆盖：

- Crystal Skins
- Elven Structure Skins
- Arcadian Premium

The repair contains 98 reviewed direct-asset text entries: 2 Crystal Skins,
42 Elven Structure Skins, and 54 Arcadian Premium entries. It includes item
names, categories, descriptions, and the relevant operation tips.

本次共补齐 98 条已审校的直接资产文本：Crystal Skins 2 条、Elven Structure
Skins 42 条、Arcadian Premium 54 条，包含物品名称、分类、说明和相关操作提示。

## Baseline Discipline / 基线隔离

- The normal package starts from the game-proven normal `0.1.24` package.
- The bilingual package starts from the game-proven bilingual `0.1.26` package.
- The two root containers were rebuilt separately; neither package reuses the
  other package's LocRes or asset triplet.

- 普通中文包以游戏内已验证的 `0.1.24` 普通中文包为基础。
- 双语包以游戏内已验证的 `0.1.26` 双语包为基础。
- 两个根容器分别重建，绝不交叉复用对方的 LocRes 或资产三件套。

## Validation / 已完成校验

- Both root IoStore containers passed `retoc verify`.
- Both ZIP archives passed CRC integrity checks.
- The rebuilt containers contain 286 packages each: the existing overlay plus
  the 46 direct-asset packages updated by this repair.
- Readback confirmed Chinese and bilingual text for representative Elven and
  Arcadian assets; Crystal Skins was included in the same generated container.

- 两个根 IoStore 容器均通过 `retoc verify`。
- 两个 ZIP 均通过 CRC 完整性校验。
- 每个新容器均含 286 个包：保留既有覆盖，并加入本次修复更新的 46 个直接资产包。
- 已从新容器回读确认 Elven 和 Arcadian 的代表性中文/双语文本；Crystal Skins 与其
  使用同一生成容器并已纳入包清单。

Container validation is not a substitute for a live game test. Please test one
item from each of the three skin mods after installation and report a screenshot
if any direct-asset text is still English.

容器校验不等同于游戏内实机验证。安装后请分别测试三套皮肤模组中的一个物品；若仍有
直接资产文本显示英文，请附截图反馈。

## Installation / 安装

1. Close the game. / 关闭游戏。
2. Extract **all files** from your chosen ZIP into
   `ARK Survival Ascended\\ShooterGame\\Content\\Paks` and overwrite matching files.
   将所选 ZIP 根目录中的**全部文件**解压到上述 `Paks` 目录，并覆盖同名文件。
3. Install normal Chinese **or** bilingual, never both.
   普通中文与双语包必须二选一，不能混装。
4. Remove old files with the same names before replacing them.
   覆盖前请先清理同名的旧测试文件。
