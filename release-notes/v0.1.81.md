# ASA 模组汉化补丁 0.1.81（V10.1 融合版）

本版以汉化组 V10.1 的普通中文、双语包为对应基线，保留汉化组已有译文的优先级，并合入此前审校过的模组汉化及侏罗纪觉醒 216 版补充内容。普通中文与双语是两个独立包，只能安装其中一种。

## 更新内容

- 适配当前 UE5.8 游戏版本；普通中文与双语分别继承对应的汉化组 V10.1 基线，不混用两种基线文件。
- 合入此前已审校、且不覆盖汉化组现有条目的模组译文；补充侏罗纪觉醒 216 版新增或变更的名称与说明。
- 修复地狱行者连发弩、巨蛛战利品与断肢、极地剑齿虎王头盔等此前发现的英文说明；批量补齐雪地吉利装备 16 条、凯夫拉装备 9 条说明。
- 根 PAK 路线已在游戏内验证可让侏罗纪觉醒的铅矿石名称显示中文。用户反馈上一轮 0.1.80 测试包目前没有发现明显问题；0.1.81 沿用其三个运行文件，未再改动译文。

## 安装

下载 `ASA_Mod_Localization_0.1.81_Normal.zip`（普通中文）或 `ASA_Mod_Localization_0.1.81_Bilingual.zip`（双语），**只选一个**。关闭游戏，备份原有汉化文件，将所选包中的 `ShooterGame-Windows_P.pak`、`.ucas`、`.utoc` 放入 `ShooterGame\Content\Paks` 并覆盖同名文件。请移走旧汉化包的 `pakchunk9999-Windows_P.pak`，不要再叠加安装汉化组 V10.1 的另一套根文件。本版不修改模组自身容器，也不需要服务器 INI 配置。

## 已知限制

- 本版并非所有模组文本的全量汉化。侏罗纪觉醒 216 版的自动审计中，仍有 138 条物品说明候选缺口；候选项尚需逐条确认是否为玩家可见文本。
- 已验证的游戏内表现不能代表全部模组、物品和双语界面均已验收。遇到英文、错译或显示溢出，请反馈补丁版本、模组版本和截图。
- 汉化组 V10.1 的文本优先；此包是玩家自制融合补丁，并非汉化组发布的原包。

两个 ZIP 的 SHA-256 校验值见同页附件 `SHA256SUMS.txt`。
