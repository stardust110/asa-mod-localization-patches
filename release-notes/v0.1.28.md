# ASA Mod Localization Patch 0.1.28
# ASA 模组汉化补丁 0.1.28

## Hotfix / 紧急热修

**Do not use `0.1.27`.** It replaced the verified `ShooterGame-Windows_P` root triplet with an asset-only container, which removed the language routing data and could make the game display English.

**请不要使用 `0.1.27`。** 该版本错误地用仅含资产的容器替换了已验证的 `ShooterGame-Windows_P` 根三件套，移除了语言路由数据，可能导致游戏显示英文。

`0.1.28` retains all four normal `0.1.24` base files byte-for-byte and all four bilingual `0.1.26` base files byte-for-byte. The skin fix is now a separate `pakchunk9998-Windows_P` IoStore overlay, rather than a replacement root container.

`0.1.28` 对普通中文完整保留 `0.1.24` 的四个基线文件，对双语完整保留 `0.1.26` 的四个基线文件。皮肤修复现改为独立的 `pakchunk9998-Windows_P` IoStore 覆盖层，不再替换根容器。

## Packages / 安装包

- Normal Chinese: `ASA_Mod_Localization_0.1.28.zip`
- Bilingual: `ASA_Mod_Localization_Bilingual_0.1.28.zip`
- 普通中文：`ASA_Mod_Localization_0.1.28.zip`
- 双语：`ASA_Mod_Localization_Bilingual_0.1.28.zip`

Choose exactly one package. Never mix normal Chinese and bilingual files.
请只安装其中一个包；普通中文与双语文件不能混装。

## Skin Repair / 皮肤修复

The independent overlay includes the 98 reviewed direct-asset texts for Crystal Skins (2), Elven Structure Skins (42), and Arcadian Premium (54).

独立覆盖层包含 Crystal Skins（2 条）、Elven Structure Skins（42 条）和 Arcadian Premium（54 条）的 98 条已审校直接资产文本。

## Validation / 校验

- Each normal root baseline file is byte-identical to `0.1.24`.
- Each bilingual root baseline file is byte-identical to `0.1.26`.
- Both new `pakchunk9998-Windows_P` containers passed `retoc verify` and each contains 286 overlay packages.
- Both ZIP archives passed CRC checks.

容器和 ZIP 已通过结构校验；仍请以游戏内显示作为最终验证。

## Installation / 安装

1. Close the game. / 关闭游戏。
2. Delete the seven `0.1.27` files from `ARK Survival Ascended\\ShooterGame\\Content\\Paks`.
   删除 `Paks` 目录内 `0.1.27` 留下的七个文件。
3. Extract **all eight files** from your chosen `0.1.28` ZIP into that same `Paks` directory and overwrite matching files.
   将所选 `0.1.28` ZIP 根目录中的**全部八个文件**解压到同一 `Paks` 目录，并覆盖同名文件。
4. Start the game, verify original-game Chinese/bilingual text, then test one item from each repaired skin mod.
   启动游戏后先确认原版文本恢复正常，再分别测试三套皮肤模组中的一个物品。
