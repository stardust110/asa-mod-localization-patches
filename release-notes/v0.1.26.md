# ASA Mod Localization Patch 0.1.26
# ASA 模组汉化补丁 0.1.26

## Bilingual Restored / 双语恢复

This release restores bilingual rendering for both original-game and mod text.
It combines the complete bilingual dictionary with the game-proven eight-path
fallback layout. It is the bilingual counterpart to the normal-Chinese v0.1.24
recovery package.

本版本恢复原版与模组文本的双语显示。它将完整双语词库与已验证的八入口回退布局结合，
是普通中文 `0.1.24` 回归包对应的双语版本。

## Verified In Game / 游戏内已验证

- `南方巨兽龙 [Giganotosaurus]` displays correctly for original-game content.
- `衰变之嗣[Scion of Degeneration]` displays correctly for Extra Bosses.
- Sweet Structures skin names display Chinese and English together.
- `X-Dream Dragon` now displays as `X-Dream 喷火龙[X-Dream Dragon]`.

- 原版南方巨兽龙正确显示为 `南方巨兽龙 [Giganotosaurus]`。
- Extra Bosses 的衰变之嗣正确显示为 `衰变之嗣[Scion of Degeneration]`。
- 甜蜜建筑皮肤名称正确显示中英双语。
- `X-Dream Dragon` 已修正为 `X-Dream 喷火龙[X-Dream Dragon]`。

## Installation / 安装

1. Close the game. / 关闭游戏。
2. Extract all four game files from `ASA_Mod_Localization_Bilingual_0.1.26.zip`
   into `ARK Survival Ascended\ShooterGame\Content\Paks` and overwrite matching files.
   将压缩包根目录的 4 个游戏文件全部解压到上述 `Paks` 目录并覆盖同名文件。
3. Choose this bilingual package **or** normal-Chinese v0.1.24, never both.
   本双语包与普通中文 `0.1.24` 必须二选一，不能混装。
4. Remove old test/candidate packages with the same filenames first.
   先删除旧测试包或候选包的同名文件。
