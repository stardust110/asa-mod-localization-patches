# ASA Mod Localization Patch 0.1.33

This correction release refines Insaluna terminology.

- Creature and character names remain in their original English: `Aros`, `Atalanta`, `Daedos`, `Harper`, `Maia`, `Malum`, `Samos`, `Tynasta`, `Unferth`, and `Oceanumors`.
- Non-creature terms with clear context are translated: Eternal Tunnels, Soulless Hollows, Coral Cliffs, Leaping Kapros tribe, altars, colored crystals, logs, and character-linked loot such as `Blood Of Samos` and `Eye of Selena`.

Both normal Chinese and name-bilingual packages use the `3+1` layout. Install exactly one ZIP. Each archive passed `UnrealPak -Test` and ZIP CRC checks.
