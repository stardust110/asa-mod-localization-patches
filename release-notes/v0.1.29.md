# ASA Mod Localization Patch 0.1.29
# ASA 模组汉化补丁 0.1.29

## Hotfix / 紧急热修

**Do not use `0.1.27`.** It replaced the verified `ShooterGame-Windows_P` root triplet with an asset-only container, which removed language routing data and could make the game display English.

**请不要使用 `0.1.27`。** 该版本错误地用仅含资产的容器替换了已验证的 `ShooterGame-Windows_P` 根三件套，移除了语言路由数据，可能导致游戏显示英文。

`0.1.29` 对普通中文完整保留 `0.1.24` 的四个基线文件，对双语完整保留 `0.1.26` 的四个基线文件。皮肤修复改为独立的 `pakchunk9998-Windows_P` IoStore 覆盖层，不再替换根容器。

## Packages / 安装包

- `ASA_Mod_Localization_0.1.29.zip`：普通中文
- `ASA_Mod_Localization_Bilingual_0.1.29.zip`：双语

只安装其中一个包，普通中文与双语不能混装。

## Skin Repair / 皮肤修复

独立覆盖层包含 98 条已审校直接资产文本：Crystal Skins 2 条、Elven Structure Skins 42 条、Arcadian Premium 54 条。

## Validation / 校验

- 普通中文根基线文件与 `0.1.24` 逐字节一致。
- 双语根基线文件与 `0.1.26` 逐字节一致。
- 新 `pakchunk9998-Windows_P` 容器通过 `retoc verify`，每个包含 286 个覆盖资产包。
- 两个 ZIP 均通过 CRC 校验。

容器和 ZIP 已通过结构校验；请以游戏内显示作为最终验证。

## Installation / 安装

1. 关闭游戏。
2. 删除 `ARK Survival Ascended\\ShooterGame\\Content\\Paks` 中 `0.1.27` 留下的七个文件。
3. 将所选 `0.1.29` ZIP 根目录中的**全部八个文件**解压到同一 `Paks` 目录，并覆盖同名文件。
4. 启动游戏后先确认原版文本恢复中文或双语，再分别测试三套皮肤模组中的一个物品。

## Checksums / 校验值

请使用本 Release 附件 `SHA256SUMS.txt` 核对文件。
