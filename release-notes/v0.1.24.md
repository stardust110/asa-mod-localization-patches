# ASA Mod Localization Patch 0.1.24
# ASA 模组汉化补丁 0.1.24

## Normal Chinese Recovery / 普通中文回归

This release restores the game-proven normal Chinese overlay from v0.1.17.
It publishes **only** the normal Chinese package. It does not include a bilingual
package and does not claim to fix the bilingual asset-localization issue.

本版本恢复已在游戏内验证有效的 `0.1.17` 普通中文覆盖层。它**只发布普通中文包**；
不包含双语包，也不宣称已修复双语资产汉化问题。

## What Changed / 本次修复

- The `pakchunk9999-Windows_P.pak` overlay is byte-identical to v0.1.17.
  No LocRes was regenerated and no IoStore asset container was fused.
- The overlay restores eight fallback paths: `Game` and `ShooterGame`, each with
  `zh`, `zh-Hans`, `ja`, and `de`. This prevents mod strings from falling back
  to English when ASA resolves through a fallback language bucket.
- The official normal-package triplet remains the matching normal baseline.

- `pakchunk9999-Windows_P.pak` 与 `0.1.17` 字节完全一致；没有重新生成 LocRes，
  也没有融合 IoStore 资产容器。
- 恢复 `Game` 与 `ShooterGame` 下的 `zh`、`zh-Hans`、`ja`、`de` 八个回退路径，
  避免 ASA 模组字符串走回退语言桶时重新显示英文。
- 保留匹配的官方正常中文三件套基线。

## Installation / 安装

1. Close the game. / 关闭游戏。
2. Extract **all four game files** from `ASA_Mod_Localization_0.1.24.zip` into
   `ARK Survival Ascended\ShooterGame\Content\Paks` and overwrite matching files.
   将压缩包根目录的 **4 个游戏文件全部** 解压到上述 `Paks` 目录并覆盖同名文件。
3. Do not keep a newer normal `pakchunk9999-Windows_P.pak` from v0.1.19-v0.1.23.
   不要同时保留 `0.1.19` 至 `0.1.23` 的普通中文同名覆盖 PAK。
4. Do not install this normal package with a bilingual package. / 不要与双语包混装。

## Verification / 验证

- Overlay SHA-256 is identical to the v0.1.17 game-proven overlay.
- ASA-compatible UnrealPak readback confirms the expected mount point and all eight
  localization paths.
- The ZIP passed CRC verification. `SHA256SUMS.txt` covers the release archive.

## Process Correction / 流程纠正

The prior bilingual investigation incorrectly reused the normal-package build path.
From this release forward, normal and bilingual packages use independent immutable
baselines, isolated output folders, separate manifests, and separate in-game
regression evidence. A bilingual experiment cannot replace a normal package.

此前双语排查错误复用了普通包构建路径。自本版本起，正常中文与双语包使用独立的
不可变基线、隔离输出目录、独立清单与独立游戏内回归证据；双语试验不得替换普通中文包。
