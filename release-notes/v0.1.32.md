# ASA Mod Localization Patch 0.1.32

## Added mod coverage

- Cliffan Backpacks: backpack names, tiered item descriptions, status text, and crafting-facing text.
- Immersive Taming: bait and bait-arrow items, taming status messages, journal/settings UI, and configuration tooltips.
- Insaluna: identified creature/item names, engrams, summon and loot text, cave hints, confirmed artifact scrolls, and player-facing descriptions.
- Zeeb's Dino Havens: haven structures, inventory/administrator UI, breeding and incubation prompts, and farming/worker descriptions.

Official ARK artifact names use their confirmed Chinese names. Mod-author proper names such as `Aros`, `Atalanta`, `Daedos`, and `Oceanumors` are deliberately retained in English when no confirmed Chinese name exists.

## Packages

- `ASA_Mod_Localization_0.1.32.zip`: normal Chinese.
- `ASA_Mod_Localization_Bilingual_0.1.32.zip`: names use `中文[English]`; long descriptions, prompts, and logs remain Chinese to avoid UI overflow.

Install exactly one package. Each ZIP contains the same four game runtime files in the `3+1` layout. Extract all four to `ShooterGame\Content\Paks` and replace the current patch files.

## Validation

- The `ShooterGame-Windows_P.pak/.ucas/.utoc` baseline trio was preserved byte-for-byte.
- Direct-asset translations were imported into isolated copies and re-exported; every selected translation was found after import.
- `UnrealPak -Test` and ZIP CRC passed for both packages.

These are structural and content round-trip checks. New mod text still requires in-game visual acceptance after installation; please report any overflow, fallback-to-English behavior, or untranslated player-facing text with a screenshot.
